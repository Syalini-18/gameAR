# Game AR

Game FPS berbasis Augmented Reality (AR) yang mengharuskan pemain melawan bot sebagai musuh. Pemain menggunakan kamera perangkat untuk berinteraksi dengan lingkungan AR dan menghadapi musuh dalam permainan.

## Fitur

* Gameplay First-Person Shooter (FPS)
* Augmented Reality menggunakan Vuforia
* Pertarungan melawan bot
* Interaksi berbasis kamera
* Sistem pertarungan untuk menyelesaikan permainan

## Platform

Android

## Teknologi

* Unity
* C#
* Vuforia Engine
